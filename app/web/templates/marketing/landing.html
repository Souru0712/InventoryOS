01 — How quantity stays true
Count · Weight · Volume

Businesses do not hold stock
one way. So we don't count it one way.

each

Count

Bagged beans, cartons, cups, pastry boxes.

Square counts it

Square owns the number. We sync it and push corrections back.

g

Weight

Flour, deli ham, beans in the hopper.

We count it

Last physical count, minus what the recipes consumed since.

ml

Volume

Milk, syrup, cold brew on tap.

We count it

One latte takes 220 ml of milk out of stock. Automatically.

Stock is shown in whatever unit you actually think in. Every physical count and every delivery re-anchors the item, so error cannot accumulate.

02 — Receiving

Photograph the delivery note. Do not type it.

The job that actually hurts is re-typing a delivery note into the POS. So don't.

01

Read. Photo or PDF, filed as the receiving record — the same invoice cannot be received twice.

02

Resolve. Each line matched to a stock item, quantities converted into base units via pack size.

03

Confirm. You approve, stock moves, and the supplier's wording is saved as an alias for next time.
